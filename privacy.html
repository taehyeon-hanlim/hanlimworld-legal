2. 앱 권한 (Android / iOS 공통)

서비스 제공을 위해 기기의 다음 권한을 요청하며, 각 권한은 명시된 목적 외에는 사용되지 않습니다. 권한은 필요한 시점에만 요청하며, 사용자가 거부해도 앱 실행 자체는 가능합니다 (해당 기능만 비활성).

권한사용 목적데이터 처리
카메라
android.permission.CAMERA
NSCameraUsageDescription		 챌린지 영상을 실시간으로 촬영해 AI 분석을 받기 위함 촬영된 영상은 사용자 확인 후 업로드. 기기에 저장되지 않으며 분석 완료 즉시 서버에서 원본 파기 (분석 결과만 보관).
마이크
android.permission.RECORD_AUDIO
NSMicrophoneUsageDescription		 영상 촬영 시 배경 음악과의 동기화(박자 싱크) 분석 오디오는 박자 감지용으로만 사용되며 별도 저장되지 않음.
사진·동영상 (갤러리)
android.permission.READ_MEDIA_VIDEO
NSPhotoLibraryUsageDescription		 기존에 촬영한 댄스 영상을 선택해 업로드하기 위함 사용자가 명시적으로 선택한 영상 파일만 접근. 전체 라이브러리 스캔 없음. 선택된 영상은 카메라 촬영본과 동일하게 분석 후 파기.
인터넷
android.permission.INTERNET		 Supabase(인증·DB), AI 분석 서버(GCP) 통신 TLS 1.2+ HTTPS 암호화 전송.

수집하지 않는 권한: 위치 정보(GPS), 연락처, SMS, 통화 기록, 블루투스, 기기 식별자(IMEI/ADID) 등은 요청·수집하지 않습니다.

  • 부정 이용 방지 및 약관 위반 대응

4. 개인정보 보유 및 이용 기간

회사는 이용자의 동의를 받아 수집한 개인정보를 회원 탈퇴 시까지 보유·이용합니다. 탈퇴 즉시 모든 식별 가능한 데이터(프로필, 분석 결과, 연습 기록)는 데이터베이스에서 영구 삭제되며, 서버 로그는 90일 내 자동 폐기됩니다.

단, 다음과 같이 관계 법령에 따라 일정 기간 보존이 필요한 정보는 해당 기간 동안 보존 후 파기합니다:

  • 전자상거래법 — 계약/청약 철회 기록: 5년 (현재 앱 내 결제 기능 없음)
  • 통신비밀보호법 — 서비스 이용 로그: 3개월

5. 개인정보의 제3자 제공 및 처리 위탁

회사는 이용자의 개인정보를 제3자에게 판매·제공하지 않습니다. 다만 서비스 운영을 위해 아래와 같이 처리 위탁하고 있습니다:

수탁자위탁 목적처리 데이터
Supabase Inc. 데이터베이스 · 인증 · 스토리지 호스팅 회원 정보, 분석 결과, 업로드 영상
Google Cloud Platform AI 댄스 분석 서버 (MediaPipe BlazePose) 업로드 영상(처리 후 즉시 삭제), 관절 keypoint
Google LLC (OAuth) Google 로그인 인증 이메일, OAuth 식별자

모든 수탁자는 개인정보 보호 조치를 취하며, 위탁 목적 외 사용하지 않습니다. 위탁 계약 상세는 요청 시 공개합니다.

6. 국외 이전

일부 처리 위탁 서비스(Supabase, Google Cloud)는 이용자의 개인정보를 한국 외 지역(미국, 싱가포르)에서 처리할 수 있습니다. 이는 서비스 제공에 필요한 최소한의 범위이며, 해당 국가의 데이터 보호 법률 및 각 업체의 국제 개인정보 보호 인증(ISO 27001, SOC 2 등)에 따라 안전하게 관리됩니다.

7. 이용자의 권리

회원은 언제든지 아래 권리를 행사할 수 있습니다:

  • 조회·수정: 앱 내 "설정 → 프로필"에서 본인 정보 확인·수정
  • 삭제 (탈퇴): 앱 내 "설정 → 계정 → 계정 삭제"에서 즉시 탈퇴
  • 처리 정지·동의 철회: support@hanlimworld.com으로 요청
  • 열람 청구: 보유 중인 본인 개인정보의 사본 요청 가능

8. 개인정보의 파기 절차 및 방법

  • 전자적 파일: DB DELETE + 복구 불가능한 로우레벨 삭제
  • 종이 문서: 분쇄 또는 소각 (현재 수집 시 해당 없음)
  • 파기 시점: 탈퇴 즉시 (사후 보존 대상 제외)

9. 개인정보 보호를 위한 기술적·관리적 조치

  • 전송 구간: TLS 1.2+ HTTPS 암호화
  • 저장: 데이터베이스 at-rest 암호화 (AES-256)
  • 비밀번호: 단방향 해시(bcrypt) 저장, 원문 비보관
  • 접근 통제: Supabase Row-Level Security 정책으로 본인 데이터만 접근
  • 로그 모니터링: 비정상 접근 탐지 시 자동 차단

10. 만 14세 미만 아동의 개인정보 보호

회사는 만 14세 미만 아동의 개인정보를 수집하지 않습니다. 만 14세 미만 아동이 회원가입을 시도하는 경우 가입이 차단되며, 실수로 가입된 경우 법정대리인의 요청으로 즉시 삭제됩니다.

11. 쿠키 및 유사 기술
