계정 및 데이터 삭제

앱 이름: 한림월드 (Hanlimworld)
개발사: Hanlimworld · 연락처: support@hanlimworld.com

한림월드 앱 이용자는 언제든지 본인 계정과 관련 데이터의 영구 삭제를 요청할 수 있습니다. 아래 두 가지 방법 중 하나를 선택하세요.

방법 1 — 앱 내에서 삭제 (즉시 처리 · 권장)

1
한림월드 앱 실행 → 로그인
2
하단 탭 "프로필" 선택
3
우측 상단 설정 아이콘 (톱니바퀴) 탭
4
스크롤 → "계정" 섹션 → "계정 삭제" 선택
5
확인 다이얼로그에서 "삭제" 탭 → 즉시 처리 완료

삭제가 완료되면 자동으로 로그아웃되며, 해당 계정으로는 다시 로그인할 수 없습니다.

방법 2 — 이메일로 요청

앱에 접근할 수 없거나 대량 삭제가 필요한 경우 아래 이메일로 요청하세요. 영업일 기준 3일 이내 처리됩니다.

support@hanlimworld.com 로 메일 작성

메일 본문에 다음 정보를 포함해 주세요:

  • 가입 시 사용한 이메일 주소
  • 계정 생성일 (대략적인 시점)
  • 삭제 사유 (선택)

보안을 위해 가입 이메일 주소와 동일한 주소에서 발신된 메일만 처리합니다.

삭제되는 데이터

요청 즉시 다음 데이터가 영구적으로 삭제됩니다. 복구 불가능합니다.

항목저장 위치
프로필 (이메일, 닉네임, 가입일)Supabase profiles 테이블
인증 정보 (비밀번호 해시, OAuth 토큰)Supabase Auth
챌린지 분석 결과 (점수, 관절 데이터)Supabase analysis_results
업로드한 댄스 영상Supabase Storage
연습 진행률 기록Supabase user_progress
앱 설정 (언어, 알림 등)Supabase user_settings + 기기 로컬

보관되는 데이터 (법령상 필수)

일부 정보는 관련 법령에 따라 최소한의 기간 동안 보관 후 파기됩니다. 이 데이터는 개인 식별 목적이 아닌 법적 의무 이행 용도로만 사용됩니다.

데이터보관 기간근거 법령
서비스 이용 로그 (IP, 접속 시간, 기기 식별자 일부) 최대 3개월 통신비밀보호법
계약·청약 철회 관련 기록 최대 5년 전자상거래법 (현재 앱 내 결제 기능 없어 해당 없음)
익명 처리된 통계 데이터 (식별 불가 집계) 영구 서비스 개선 목적 · 개인정보 아님

보관 기간이 경과한 모든 데이터는 자동으로 영구 파기됩니다.

제3자 서비스의 데이터 처리

한림월드는 아래 서비스를 처리 위탁 중이며, 계정 삭제 시 한림월드의 요청에 따라 해당 서비스에서도 즉시 삭제됩니다.

  • Supabase: 데이터베이스 · 인증 · 스토리지
  • Google Cloud Platform: AI 분석 서버 (영상은 분석 즉시 파기됨)
  • Google OAuth: Google 로그인 사용 시. 한림월드는 토큰만 삭제하며 Google 계정 자체 삭제는 Google 계정 설정 에서 별도 처리해주세요.
삭제는 되돌릴 수 없습니다. 분석 결과, 연습 기록, 챌린지 히스토리가 모두 영구 삭제되며 복구 불가능합니다. 삭제 후 재가입 시 새 계정으로 처리됩니다.
