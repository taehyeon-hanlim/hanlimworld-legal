# hanlimworld-legal

## 공개 URL

- 법적 고지 홈: https://taehyeon-hanlim.github.io/hanlimworld-legal/
- 개인정보처리방침: https://taehyeon-hanlim.github.io/hanlimworld-legal/privacy.html
- 이용약관: https://taehyeon-hanlim.github.io/hanlimworld-legal/terms.html

## 용도

- App Store Connect / Google Play Console 제출 시 요구되는 공개 URL
- 앱 내 법적 고지 링크 (외부 링크 / 앱 내 임베드용)
